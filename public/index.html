How it's built

Business tools over MCP

Customers, jobs, invoices and revenue are MCP tools. The assistant discovers them at startup, so adding a tool to the server needs no change to the AI code.

Approval is enforced in code

Tools that change data are marked by the server, and the host turns every such call into a pending action. The AI can't skip it, and it's told nothing is done until a person approves.

Roles and an audit trail

Reminders and reschedules need the dispatcher, refunds need the owner. Each action runs once, even on a double click, and every decision is logged.

The server double-checks

Inputs are validated again by the MCP server: no refund above what was paid, no reschedule onto a busy technician or outside opening hours.
